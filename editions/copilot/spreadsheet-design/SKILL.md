## Improve the requested output

1. Review the existing sheets, table headers, filters, freeze panes, print settings and related charts within scope. Identify protected, spill and add-in ranges. Keep source tables and formula dependencies intact.
2. Use a restrained visual hierarchy. Make the title, reporting period, currency or scale, column headers, subtotals and totals easy to scan. Use alignment, spacing and limited emphasis before adding color. Keep data tables compact and existing navigation usable. Use explicit labels or symbols when color carries information.
3. Use consistent number formats for comparable measures. Align figures for comparison and show material precision, signs and units. Keep true zero, missing data and suppressed values distinguishable. Keep identifiers stored as text where the source uses text. Formatting must preserve stored precision and values.
4. Use charts only when they serve the request. For magnitude comparisons, use aligned marks on a common scale when appropriate. Check axes, signs, units, labels and contrast. Preserve relevant uncertainty and avoid decoration that competes with the figures.
5. Apply authorized changes only to the relevant workbook region. Preserve existing structure, table names, formulas, data types, conditional rules and anything outside that scope. Use no extra sheets, dashboards or review artifacts unless requested.

## Verify the result

Read back the changed ranges and spot-check representative formulas and values against the original. If Excel or a supported renderer is available, inspect the actual output at its intended zoom, screen size or print layout. Check for clipping, unreadable labels, hidden negative values and ambiguous units. If visual inspection is unavailable, give specific located observations from the available evidence and state the visual limit. Return the improved workbook or requested findings and material unresolved issues.
