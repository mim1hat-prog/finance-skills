# Design

Use the reviewed dot. foundation under `branding/dot/`. Its original tokens,
components and licence are preserved; `source.json` records the upstream
revision and SHA-256 hashes. Product CSS uses a deep green accent on the shared
warm ivory surface, with a separately checked light green accent in dark mode.
This project uses the foundation without claiming registered suite membership.

The catalogue is an editorial task library: one edition selector, labelled
search, a focus filter and readable skill rows. Keep titles descriptive and
each download connected to its platform. Counts and review dates come from the
generated catalogue. Do not add invented metrics, ratings, testimonials,
tracking, CDN assets or decorative dashboards.

Use system typography, generous margins, a restrained circle mark and quiet
rules. Preserve the 44-pixel minimum for primary controls, semantic headings,
visible keyboard focus, native radio/select behavior, a live result count,
clear empty states, theme support and reduced-motion alternatives. Narrow
screens stack content without horizontal scrolling. Prompt copy must report
clipboard failure and offer selectable text.

Read `site/index.html` without JavaScript to verify the setup guide and file
fallbacks remain usable. Check the actual catalogue at desktop and phone
widths in both appearances after UI changes. Run Hallmark and Impeccable where
available, reviewing findings against the adopted identity. These checks do
not establish that a skill was imported into a workplace tenant.

The original vector artwork in `assets/` is for repository presentation. Use
the employer's approved templates for work output; this repository's brand is
not an employer template.

The coverage figure is a generated descriptive research graphic. Show actual
numerators, denominators, units, missing coverage and limits; its bars do not
represent model effectiveness. Keep the full numerical report accessible as
Markdown and JSON. Edit the catalogue template, not generated HTML. Include
the actual skill text and links before JavaScript enhancement; do not invent
ratings, users, deployment URLs or academic claims for search metadata.
