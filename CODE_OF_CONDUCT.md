# Code of conduct

This project welcomes people with different backgrounds, experience and ways of working. These expectations apply to repository issues, pull requests, reviews and other spaces maintained for this project.

## Participation

- Discuss the work respectfully. Explain disagreements with evidence and accept corrections.
- Make room for questions and different levels of experience. Critique a proposal or result without attacking a person.
- Respect privacy and ownership. Share only material you are allowed to publish; use independently invented examples for work-related problems.
- Avoid harassment, discrimination, threats, sexualized remarks, impersonation, repeated unwanted contact, spam and disclosure of another person's private information.

## Moderation and reporting

The repository owner, [mim1hat-prog](https://github.com/mim1hat-prog), and designated maintainers are responsible for moderation. They may request changes, hide or remove content, close a conversation or restrict participation according to its severity and context. They should explain decisions where doing so does not disclose sensitive information.

Use the available GitHub **Report content** or **Report abuse** options for sensitive conduct concerns; follow [GitHub's reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reporting directly to repository administrators depends on the options GitHub exposes. Do not create a public issue containing private incident details or evidence. For security and data exposure concerns, see [SECURITY.md](SECURITY.md).

This project does not promise a private reporting channel or response deadline. Non-sensitive questions about moderation can be raised respectfully in the existing conversation without repeating the disputed material.

These are original project rules. GitHub's own terms and community policies also apply.
