# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and JavaScript. Local catalogue data and vendored dot. design
tokens. No browser runtime dependencies, CDN requests, analytics or login.

## Users
Finance and controlling professionals using Microsoft Copilot or Gemini on a
Windows 11 work PC, with optional Python and Power BI workflows.

## Product Purpose
Help a person find a repeatable method for a finance task, inspect its
instructions and obtain the right assistant's package. Keep source review,
package validation and installation in a workplace account distinct.

## Primary action
Choose an assistant and download a versioned edition, the complete release or
an individual skill. Make the Excel agent Instructions text easy to obtain.

## Content and publication
Show general methods, public source references and synthetic examples. Keep
business data, internal SharePoint content, credentials, employer assets and
private project context in the approved workplace environment.

## Ownership

The repository owner is `mim1hat-prog`, with publication at
`mim1hat-prog/finance-skills`. Maintain it through that connected account.
A finance skills library with a shared canonical source and generated Copilot
and Gemini editions. Repository maintenance updates downloadable packages;
it does not silently replace skills already imported into an account.
