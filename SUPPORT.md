# Support

Start with the [quick start and downloads](README.md), then use the [Copilot guide](docs/COPILOT.md), [Gemini guide](docs/GEMINI.md) or [Windows guide](docs/WINDOWS.md). Check [release notes and checksums](releases/README.md) when a downloaded copy differs from the current source.

## Report a problem or suggest a skill

Search the [existing issues](https://github.com/mim1hat-prog/finance-skills/issues) first. For a new public report, choose [Bug report](https://github.com/mim1hat-prog/finance-skills/issues/new?template=bug_report.md) or [Skill request](https://github.com/mim1hat-prog/finance-skills/issues/new?template=skill_request.md).

Include the release version, skill name, assistant surface or local tool, an independently invented example, and the expected and observed result. Describe the available feature without identifying a private account or organization. Report whether the failure concerns a download, instructions, calculation helper or native host behavior.

**Public issues and pull requests must contain no company data.** Do not attach workbooks, screenshots, prompts, logs, internal links, names, identifiers, mappings or examples derived from real work. Reproduce the problem from invented inputs. For credentials, sensitive vulnerabilities or exposed private information, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.

## Maintainer and scope

The repository owner, [mim1hat-prog](https://github.com/mim1hat-prog), maintains this project. Contributions follow [CONTRIBUTING.md](CONTRIBUTING.md) and the [code of conduct](CODE_OF_CONDUCT.md). Support is provided as capacity permits; no response time or service agreement is promised.

Repository maintainers can investigate generic instructions, packaging and local tools. They cannot grant tenant access, change an assistant's subscription limits or verify a private workbook. See the [validation record](docs/VALIDATION.md) for what has actually been tested.
