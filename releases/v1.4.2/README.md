## Release notes

Package prepared **2026-11-25**. Remote publication is verified separately.

### Graphs on the GitHub homepage

The root README embeds the coverage graphic directly from the current branch. The graph, numerical summary and public-data context are generated together; build checks reject missing/stale generated content and a coverage block moved below the quick start. Visitors do not need to download a ZIP or open a separate site to see the chart.

### Updates and dates

Every reviewed change to skills, evidence mappings or retained datasets regenerates the chart and its README block. Maintenance checks the published main-page graph and source hashes. Source, graph and README changes are published together after validation. A scheduled check or successful local build is not proof of a successful push.

The chart and README distinguish repository version/release date from the actual observation periods and retrieval timestamps recorded in public snapshots. No provider query runs when GitHub renders the README, and package builds do not make observations newer. Failed upstream retrieval or publication remains visible as a gap.

Finance instructions, benchmark observations and previous frozen releases remain unchanged. No native model performance, public-data completeness or continuous availability is claimed.
