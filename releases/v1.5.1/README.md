## Release notes

### Complete workflows with fewer companion files

The v1.5.0 Copilot suite was reported rejected by a native import screen. Its uploaded bytes matched the published ZIP and passed independent ZIP, UTF-8, YAML and resource-link checks. It nevertheless had 29 companion files, exceeding the 20-companion limit documented for Copilot Cowork. The generic error did not establish the exact host or whether size, content, account policy or another check caused that attempt to fail.

This release retains all 29 complete workflow bodies and one finance-suite registration, grouping the procedures into nine category reference files. Each suite has ten Markdown files overall. The root routes each workflow to its category file and named section; the external manifest records exact body byte ranges, body hashes and canonical source hashes. Individual packages and copy-only Markdown remain available.

The build checks the separate companion and archive ceilings, valid metadata, safe paths, root length, complete routing and byte-for-byte canonical content. It keeps legacy layouts verifiable and preserves every earlier release. These checks do not reproduce Microsoft's platform Responsible AI screening or prove import and resource access in a work tenant.

### Import or replace

Use the complete v1.5.1 Copilot suite ZIP on the supported skill-upload screen. For Excel's OneDrive route, replace the complete finance-suite folder and Refresh. Preserve private customizations first, and remove obsolete generated references by replacing the old folder rather than merging layouts. The Gemini suite uses the same grouped layout with its own host guidance.

See [single-import setup](../docs/SINGLE-IMPORT.md) and [Copilot rejection troubleshooting](../docs/COPILOT.md#troubleshoot-unsupported-invalid-import-limit-or-responsible-ai-errors). The unchanged canonical defaults still prioritize available authorized enterprise evidence, independent calculation checks and existing workbook logic without unsolicited audit worksheets. Public benchmark observations and retrieval timestamps are unchanged.

### Validation evidence

170 Python tests passed with zero skips; all 189 generated artifacts matched their sources. The grouped archives preserve the exact canonical bodies and legacy release checks. An independent local reconciliation read the grouped procedure sections and returned the expected arithmetic while retaining unmatched records. Native Microsoft/Gemini acceptance is still unverified.
