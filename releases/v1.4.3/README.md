### Weekly maintenance

The existing maintenance task now runs on **Wednesdays at 08:00 Asia/Tokyo**, with the first weekly check on **2026-12-02**. The scheduling service confirmed the change on 2026-11-25; the README and maintainer instructions now describe this cadence. No second daily task was created.

Each validated repository update still regenerates the homepage chart and numerical summary together. The weekly check reviews the published graph, official platform guidance and relevant upstream changes. It does not turn the README into a continuously running collector or replace imported Copilot/Gemini copies automatically.

Finance procedures, public benchmark observations and acquisition timestamps are unchanged. Earlier frozen packages retain their original contents and checksums. The package version changes because the full release includes the revised maintenance instructions.
