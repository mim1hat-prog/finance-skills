## Release notes

Package prepared **2026-11-25**. Remote publication is verified separately.

### Coverage on the homepage

The GitHub README now opens with a compact dot. header, direct Markdown/full downloads and the generated coverage graphic before the quick start. A readable numerical fallback is generated from the same inventory as the chart. The static catalogue also shows coverage before its long skill list.

The design follows reviewed presentation patterns from uv, FastAPI and Ollama: clear purpose, concise navigation, useful evidence, platform-specific download choices and a concrete starting example. Their adoption and performance results are not attributed to this library.

### Donation links removed

The current catalogue template and generated page no longer include a donation link. Future builds preserve this change. Existing frozen release archives retain their original bytes for reproducibility.

### Publication and compatibility

Authenticated Git publication is supported when a connector cannot preserve verified public no-reply author and committer identities. Historical repair requires the exact reviewed replacement history and an explicit expected-head lease. Authentication, remote publication and repository settings are verified separately from package generation.

The library still has 29 canonical skills and 60 copy-ready Markdown files. Finance methods, benchmark observations and previous frozen releases are unchanged. Source counts and their limits remain in the generated coverage report; package tests do not establish native Copilot/Gemini task success.
