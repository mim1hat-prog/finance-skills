## Release notes

Package prepared **2026-11-26**. Remote publication and native host activation are verified separately.

### One import for all workflows

The new Copilot and Gemini complete-suite ZIPs each contain one `finance-suite` skill with all 29 finance workflow references. Upload the selected suite ZIP unchanged. Its main file provides the host instructions, shared controls, core operating rules and workflow routing index; supporting files hold the complete canonical procedures.

This creates one installed skill, not 29 separately registered skills. It does not bypass a host's skill limit, provide missing connectors or claim access to local Python. The instructions require the model to read the applicable reference before using it and identify unavailable resources. A representative task in the approved host is still necessary to verify resource access and routing.

### Downloads and updates

Versioned releases now provide seven ZIP downloads: the two complete suites, the original Copilot/Gemini/all individual-package transport bundles, copy-only Markdown and the full project. The full project includes expanded suite folders and external member manifests. Earlier four- and five-archive releases retain their original bytes and remain verifiable.

Replace a suite with the complete newer package and all references, or update the complete Excel folder and Refresh. GitHub maintenance does not update an imported copy automatically. Individual native workflows and copy-and-paste instructions remain available when a narrower workflow or fallback is preferable.

Canonical finance procedures and public benchmark observations remain unchanged. Suite generation is a packaging and routing feature; no measured improvement in model accuracy or successful native import is claimed.
