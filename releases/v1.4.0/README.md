## Release notes

Package prepared **2026-11-25**. Remote publication is verified separately from the package checks below.

### Easier to discover and use

The project opens with a concise Markdown quick start and an independently invented reconciliation example. A complete static catalogue includes all skill descriptions, prompts and Copilot download links before JavaScript adds filters and edition switching. Search titles, descriptions and SoftwareSourceCode metadata describe the actual repository without ratings or adoption claims.

Prepared GitHub description/topics remain separate from repository settings. Support guidance, an original code of conduct, public-data-only issue templates and a PR checklist provide practical contribution routes. A proposed native evaluation protocol explains matched baseline comparisons and their limits; it is not a completed study.

### Reproducible descriptive coverage

`metrics/summary.json`, `metrics/README.md` and `assets/coverage.svg` derive counts from canonical skill contracts, active source mappings, test references and retained public snapshots. They expose numerators, denominators, missing evidence, observation periods and source hashes. Original and derived rows are separate; synthetic fixtures and repeated vintages do not inflate public-data totals.

The reports measure repository contents and declared evidence links. They do not measure model accuracy, financial-domain completeness, active users or search performance.

### Publication privacy

The new read-only Git identity guard checks author and committer fields without printing names, addresses or messages. Source/release scans and commit metadata checks are separate. A connector that cannot select author/committer identities must not be used to repeat an unresolved identity finding. A supported publication route must verify the public identity independently.

Canonical finance instructions, public benchmark values and existing versioned release files are unchanged. Existing Copilot/Gemini copies still require replacement or Refresh when an update is published.
