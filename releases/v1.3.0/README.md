## Release notes

Released **2026-11-25**.

### Markdown only, ready to copy and paste

The new `finance-skills-v1.3.0-markdown.zip` contains 60 Markdown files:

- `copilot/`: all 29 Copilot skill instructions.
- `gemini/`: all 29 Gemini skill instructions.
- `EXCEL-AGENT-INSTRUCTIONS.md`: the shared Excel agent profile.
- `START-HERE.md`: a short Windows copy-and-paste guide.

Extract the ZIP, open the relevant file in VS Code or Notepad, copy its entire contents and paste into an available agent/Gem Instructions field or an approved conversation. The generated skill files omit YAML headers and retain the complete edition-specific instructions and shared controls. Use one relevant workflow at a time.

Every member of this ZIP is `.md`. Its checksum and file inventory are external. Native import packages and the complete project remain separate downloads; the full release also includes this Markdown archive and its inventory.

### Version and verification

The build derives these files from the same canonical skills as the native editions. Deterministic packaging checks cover exact member names, complete bodies, UTF-8 text and hashes. Release checks support the new five-archive format and continue enforcing the original four-archive format for historical versions.

Canonical finance procedures, public benchmark observations and research records are unchanged. Published v1.1.0 and v1.2.0 snapshots remain immutable. Pasted or imported copies in Copilot and Gemini require their own replacement or Refresh step; this release does not establish installation or execution in a work account.
