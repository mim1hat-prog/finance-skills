## Release notes

### Excel setup

Use **finance-skills-v1.6.0-excel-onedrive.zip** for Copilot in Excel. Extract it in Windows, then add the inner **finance-suite** folder to the OneDrive skills folder opened by Excel. Keep `SKILL.md` and all nine `references` files together. Select **Refresh** and invoke **@finance-suite**. The archive itself is a transport download; it is not an Excel ZIP import.

The Chat and Gemini suite downloads remain native ZIP packages. Each format contains all 29 workflows in one registered suite. Folder and package checks do not establish acceptance, automatic activation or reference access in a work account.

### Cleaner instructions and repository

- Condense repeated Excel operating instructions and host output rules while preserving enterprise-first retrieval, independent checks, existing business logic, concise results and no unsolicited audit sheets.
- Complete authorized changes when capabilities and preconditions permit; keep uncertain actions subject to independent readback.
- Explain that copying the suite's root alone does not include its supporting procedures.
- Remove the unused current banner, shorten repeated README prose and replace the long current validation chronology with a concise record linked to preserved history.

### Evidence and reproducible evaluation

- Correct the FAIR paper from empirical research to metadata guidance. The homepage reports source composition separately from local test links and native execution evidence.
- Link existing relevant calculation, workbook and SQL helper tests to four more workflows. These are partial local checks, not native task results.
- Add four synthetic development cases: reconciliation, quantity/price/FX decomposition, ambiguous mapping and forecast-cutoff handling. Prompts and answer keys have versioned hashes.
- Prepare reproducible baseline-versus-suite plans and summarize manually recorded results with explicit missing and failed runs, unique-case denominators and paired outcomes. Public answer keys make this a development kit, not a hidden benchmark. No Copilot/Gemini study has been run with it.

### Compatibility and validation

The release adds an eighth download under manifest schema 4. Schemas 1–3 and every existing frozen release remain verifiable. The shared canonical library still generates individual skills, complete suites and Markdown-only copy files.

See the [current validation record](https://github.com/mim1hat-prog/finance-skills/blob/main/docs/VALIDATION.md), [Excel setup](https://github.com/mim1hat-prog/finance-skills/blob/main/docs/COPILOT.md#3-copilot-in-excel), [evaluation protocol](https://github.com/mim1hat-prog/finance-skills/blob/main/docs/EVALUATION.md) and [measurement methods](https://github.com/mim1hat-prog/finance-skills/blob/main/metrics/README.md).

Maintenance remains weekly on Wednesdays at 08:00 Asia/Tokyo. Replacing a package in GitHub does not replace an installed work-account copy.
